这是一个无需云端 AI API 的平面图识别与标注小程序。我的要求是：
1. 墙体标注为红色中心线，窗户处保持连续；真正的门洞不能用红墙封住。
2. 门洞用黄色直线标注，画在关闭位置，不要描开门圆弧。
3. 楼梯间（包括合适的平台）用 50% 透明绿色多边形标注。
4. 保留原始平面图，支持拖动修正、增删、撤销和 PNG/SVG/JSON 导出。

当前版本是传统图像处理的启发式原型，没有附带训练好的模型。请先确认现有功能能运行，用 examples/example.png 测试并指出具体漏标、误标，然后改进通用算法。不要将示例图的坐标硬编码成自动识别。不要直接承诺识别准确率。

如果规则识别达不到要求，请提出并在我选择后接入本地预训练模型，检查模型许可、类别和权重，保持现有输出坐标与编辑界面不变。默认不要接收费 API 或云端上传。
